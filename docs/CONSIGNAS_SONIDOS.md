# Consignas grabadas para «Jugar con los sonidos»

Las diez consignas grabadas por el docente se reproducen únicamente cuando el niño toca el botón de consigna. Los audios actuales de fonemas, palabras y sílabas no se sustituyen. Los originales se guardan en `inputs/audio_final/instrucciones/`.

| Archivo | Frase exacta |
| --- | --- |
| `reconocer.m4a` | ¿Oyes este sonido en la palabra? |
| `posicion-inicio.m4a` | ¿Oyes este sonido al principio? |
| `posicion-final.m4a` | ¿Oyes este sonido al final? |
| `posicion-centro.m4a` | ¿Oyes este sonido en medio? |
| `aislar-inicio.m4a` | ¿Cuál es el primer sonido? |
| `aislar-final.m4a` | ¿Cuál es el último sonido? |
| `integrar-dos.m4a` | Junta los sonidos. ¿Qué sílaba forman? |
| `integrar-tres.m4a` | Junta los sonidos. ¿Qué palabra forman? |
| `segmentar-dos.m4a` | Coloca en orden los sonidos de esta sílaba. |
| `segmentar-tres.m4a` | Coloca en orden los sonidos de esta palabra. |

En «Escuchar en un lugar», la consigna de inicio corresponde a los ítems 1–4, la de final a los ítems 5–8 y la de medio a los ítems 9–12. El archivo original de inicio se llama `posición-inicio.m4a`; se asocia internamente con `posicion-inicio` sin modificar su contenido. Cada sonido y cada palabra se reproducen por separado y solo al tocarlos.
