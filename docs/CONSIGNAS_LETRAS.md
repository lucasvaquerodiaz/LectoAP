# Consignas grabadas para «Jugar con las letras»

Las ocho consignas grabadas por el docente se reproducen únicamente cuando el niño toca «▶ Consigna». Los originales se guardan en `inputs/audio_final/instrucciones/` y se usan tanto en el recorrido como en los juegos individuales.

| Archivo | Frase exacta |
| --- | --- |
| `letra-sonido.m4a` | ¿Cómo suena esta letra? |
| `sonido-letra.m4a` | ¿Qué letra corresponde a este sonido? |
| `imagen-letra.m4a` | ¿Con qué letra empieza? |
| `leer-silaba.m4a` | ¿Cómo suena esta sílaba? |
| `dictado-silaba.m4a` | Forma la sílaba que oyes. |
| `leer-imagen.m4a` | Lee la palabra y toca su dibujo. |
| `construir-palabra.m4a` | Forma la palabra del dibujo. |
| `dictado-palabra.m4a` | Forma la palabra que oyes. |
