# Criterios pedagógicos de LectoAP

La conciencia fonémica permite atender a los sonidos del habla, identificarlos y operar con ellos. El código alfabético conecta esos sonidos con grafías. Son aprendizajes relacionados pero no equivalentes: una tarea de conciencia fonémica no debe resolverse leyendo letras. Por ello las pantallas CF del alumno no muestran las palabras ni sus grafías, tampoco al corregir. Las palabras usan grabaciones reales cuando existen. Las fichas escritas de preparación aparecen como apoyo docente si falta una grabación, y no se enseñan al alumno.

La secuencia recomendada es reconocer → aislar → segmentar → integrar. El docente elige en función del aprendizaje observado; no hay una escalera impuesta por puntuaciones. CF08 es una extensión de sustitución, no requisito. En CF06 se elige cada fonema mediante audio y se coloca en una caja: la respuesta exige secuencia, no solamente contar golpes o sílabas. La integración permite escuchar sonidos separados y reconocer su palabra; se oculta el nombre oral de las opciones porque revelaría la respuesta.

Las correspondencias se practican en ambas direcciones. La construcción por toque conecta sonido, grafía y orden; el dictado puede mostrar el significado tras la respuesta. Una letra se puede repetir (OSO necesita dos O). Las vocales acentuadas mantienen su grafía; /o/ no se confunde con la identidad gráfica de Ó. B/V, C contextual, H y dígrafos tienen entradas gráficas separadas: las palabras se transcriben explícitamente y no se calculan fonemas separando automáticamente las letras.

Las estructuras V, CV, VC, CVC, VCV, CVCV, CVCVC y CVCVCV están declaradas. Una introducción elegida por el docente permite tres ítems del mismo patrón. Después se priorizan las estructuras menos practicadas de entre las compatibles y se evita repetir el objetivo inmediato cuando hay alternativas. El límite orientativo del 60 % no puede garantizarse si el filtro deja una única estructura; no se fabrican palabras para aparentar diversidad. No se generan pseudopalabras polisilábicas.

El 80 % de aciertos es una orientación para ofrecer reto accesible, no una medida diagnóstica. Se usan primeras respuestas, una ventana de hasta diez y un mínimo de cinco observaciones. Un error aislado no altera la dificultad. Los reintentos y el modelado ayudan a aprender y no aumentan artificialmente el cálculo de aciertos. La adaptación modifica una dimensión cada vez en los motores con alternativas graduables; las estructuras trabajadas y la longitud máxima quedan bajo control docente.

El módulo combinado necesita confirmación docente de haber trabajado conciencia fonémica y correspondencias por separado. La comparación de grafías no sustituye la comparación oral: se recomienda pronunciar ambas palabras y señalar el cambio. Vocabulario es complementario, con denominación y función; no condiciona el avance en alfabetización.

Las tandas breves, el feedback inmediato, la consigna única y la interfaz predecible buscan aumentar oportunidades de respuesta con baja carga cognitiva. No hay premios competitivos, cronómetro ni evaluación clínica. Familiarizar previamente con las denominaciones de los pictogramas evita que una ambigüedad léxica se interprete como un error fonémico. No existe reconocimiento automático de la pronunciación del alumno.

Base documental: especificación proporcionada por el usuario. La carpeta inicial no contiene publicaciones de los autores mencionados en ella; no se han inventado referencias ni copiado ejercicios. Se requiere pilotaje con docentes/alumnado para valorar claridad y utilidad, especialmente el vocabulario y el salto al módulo combinado.
