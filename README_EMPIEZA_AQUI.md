# LECTOAP — EMPIEZA AQUÍ

Este paquete está pensado para abrirse como carpeta/proyecto en Codex.

## Contenido
- `PROMPT_MAESTRO_CODEX.md`: especificación completa para Codex.
- `inputs/audio_final/fonemas/`: 9 fonemas definitivos + manifiesto.
- `inputs/audio_final/palabras/`: 19 palabras definitivas + manifiesto.

## Flujo recomendado
1. Descomprime `LectoAP_STARTER.zip` en una carpeta local llamada `LectoAP`.
2. Abre la aplicación de escritorio de ChatGPT y cambia a **Codex**.
3. Abre/selecciona la carpeta local `LectoAP` como proyecto o carpeta de trabajo.
4. Inicia un chat NUEVO dentro de Codex para este proyecto.
5. Abre `PROMPT_MAESTRO_CODEX.md`, copia todo su contenido y pégalo como primer mensaje.
6. Indica a Codex que trabaje directamente dentro de esa carpeta y que empiece.
7. NO vuelvas a adjuntar el audio: las dos carpetas `inputs/audio_final/` son la única fuente de verdad.

Más adelante, cuando Codex haya creado el repositorio, se puede conectar/publicar en GitHub.
